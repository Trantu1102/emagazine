# The Green Heart of Suntory PepsiCo in Asia

English edition of the long-form article on the Suntory PepsiCo Long An Factory in Tay Ninh — a USD 300 million investment and the largest production facility of either Suntory or PepsiCo in Asia-Pacific.

A static site: `index.html`, `style.css`, `main.js`, plus `images/` and `videos/`. No build step — open `index.html`, or serve the folder with any static server.

```bash
python3 -m http.server 8000
```

## Structure

| File | What it holds |
| --- | --- |
| `index.html` | The whole article: hero, standfirst, four chapters, infographic, scrollmation, companion-article grid |
| `style.css` | Design tokens, layout, reveal animations, responsive rules |
| `main.js` | 3D hero droplet (three.js), scroll reveals, counters, scrollmation, lightbox, progress bar |
| `images/`, `videos/` | Photography and the chapter 2 clip |

Translated from the Vietnamese edition ("Trái tim xanh của Suntory PepsiCo tại châu Á"). Vietnamese personal and place names are transliterated without diacritics.
